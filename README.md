# Miami Wind Omarchy Theme
An Omarchy theme based on Miami Wind color scheme which is a blend of colors from [Tailwind CSS](https://tailwindcss.com/docs/colors) and Grayscale colors from [Catppuccin Mocha](https://catppuccin.com/) with inspiration from the theme [Miami Nights](https://github.com/monkeytypegame/monkeytype/blob/master/frontend/static/themes/miami_nights.css) for [Monkeytype](https://www.monkeytype.com). Color Swatches built using [Coolors](https://coolors.co/)

## Installation

```bash
omarchy theme install https://github.com/hanakin/omarchy-miami-wind-theme
```

That is the whole install. The theme is colors only: `colors.toml` drives the terminals, Hyprland borders, editors and the rest of Omarchy through its templates, alongside the shipped btop and Chromium colors, the icon setting and the backgrounds.

The icon setting is `Flatery-Pink-Dark`. It only takes effect when the [Flatery](https://github.com/cbrnix/Flatery) Pink Dark icons are installed (together with the `Flatery` and `Flatery-Dark` base directories they link to). Without them, apps fall back to the default GTK icons.

The Starship prompt, Fastfetch configuration, About launcher, Flatery icon download, VS Code extension and terminal font settings are not part of the theme. They live in the separate [hanakin/omarchy-setup](https://github.com/hanakin/omarchy-setup) configs repo.
